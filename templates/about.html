About CAREER GUIDANCE PLATFORM

"Explore Your Skills, Discover Your Career, Build Your Future."

Project Objective

Empowering Students to Overcome Career Uncertainty

Many college and final-year students face common hurdles: not knowing which technical track to pursue, confusion over which frameworks to learn, difficulty preparing resumes, and lack of interview preparation.

CAREER GUIDANCE PLATFORM addresses these problems in one centralized place by combining intelligent career assessments, structured roadmaps, skills development, interview question banks, and fresher job opportunities.

Intelligent Career Assessment

Algorithm-backed questionnaire evaluating technical and analytical interests.

Tiered Learning Roadmaps

Beginner, Intermediate, and Advanced milestones with practical exercises.

Placement Preparation Bank

Technical Q&A, HR interview responses, and aptitude breakdowns.

Technical Architecture

Frontend Architecture

HTML5, CSS3, Modern JavaScript

Custom design system, CSS variables, responsive grid, and AJAX topic progress tracking.

Backend Framework

Python & Flask Framework

Modular blueprint architecture (auth, student, career, admin) with secure session handling.

Database Engine

MySQL Relational Database

11 normalized relational tables with parameterized queries preventing SQL injection.
